Assistance

Quelque chose ne fonctionne pas, ou une question ? Écrivez-nous par e-mail et nous vous répondrons dès que possible, généralement sous deux jours ouvrés.

Nous contacter

eliastestdev@gmail.com

Précisez-nous le modèle d'iPhone et la version d'iOS, et s'il s'agit de votre téléphone ou de celui de votre enfant.

Écrire à l'assistance

Le blocage ne s'applique pas

  • Vérifiez que le téléphone de votre enfant est connecté à Internet. Le blocage arrive dès qu'il est de nouveau en ligne.
  • Une application déjà ouverte est bloquée dès que votre enfant change d'app ou déverrouille l'écran.
  • Ouvrez Blok sur le téléphone de votre enfant et vérifiez que vous avez choisi les applications à bloquer. Si aucune application n'est choisie, rien n'est bloqué.
  • Temps d'écran doit être autorisé sur le téléphone de votre enfant. Ouvrez Blok sur ce téléphone : l'app vous indique s'il manque quelque chose.

J'ai oublié le code PIN parent

Ouvrez Blok sur votre téléphone, allez dans « Settings » (réglages de Blok) et touchez le téléphone de votre enfant. Le code de récupération s'y trouve.

Changer de téléphone ou l'associer à nouveau

Sur votre téléphone : « Settings » dans Blok, touchez le téléphone de votre enfant et choisissez « New pairing code » (nouveau code d'association). Saisissez ce code dans Blok sur le téléphone de votre enfant.

Abonnement

  • Résilier : ouvrez Réglages sur votre iPhone, touchez votre nom, puis Abonnements.
  • Nouveau téléphone ? Touchez « Restore purchases » (restaurer les achats) dans Blok.
  • Les remboursements sont gérés par Apple : reportaproblem.apple.com.
  • Le déblocage fonctionne toujours, même sans abonnement.

Supprimer votre compte et vos données

Dans Blok sur votre téléphone : « Settings », puis « Delete account » (supprimer le compte). Tout est effacé. Vous pouvez aussi nous écrire par e-mail. En savoir plus dans notre politique de confidentialité.
