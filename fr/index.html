Contrôle parental pour iPhone

Bloquez le téléphone de votre enfant depuis le vôtre.

Un appui sur LOCK et les applications choisies sont bloquées sur l'iPhone de votre enfant. Repas, devoirs ou coucher : c'est vous qui décidez quand faire une pause d'écran.

Bientôt disponible sur l'App Store Comment ça marche

Pour iPhone sous iOS 16 ou version ultérieure, sur votre téléphone comme sur celui de votre enfant.

Qu'est-ce que Blok ?

Blok est une application de contrôle parental pour iPhone. Vous bloquez à distance les applications de votre choix sur l'iPhone de votre enfant, depuis votre propre téléphone, en un seul geste. Le blocage peut durer jusqu'à ce que vous le leviez, pendant une durée définie, ou suivre des horaires pour l'école et le coucher.

C'est Temps d'écran d'Apple qui applique le blocage : il tient même si l'app est fermée ou si le téléphone redémarre. Blok bloque des applications ; il ne surveille pas votre enfant.

Comment bloquer l'iPhone de votre enfant

Opérationnel en quelques minutes. Aucun compte pour votre enfant, aucun réglage compliqué.

  1. 1

    Installez Blok sur les deux téléphones

    Choisissez « Parent » sur votre iPhone et « Child » (enfant) sur celui de votre enfant.

  2. 2

    Associez-les avec un code

    Saisissez le code affiché sur votre téléphone, autorisez Temps d'écran et choisissez les applications à bloquer.

  3. 3

    Appuyez sur LOCK

    Où que vous soyez. Débloquez tout aussi facilement, ou laissez un blocage minuté le faire pour vous.

Questions sur le contrôle parental

Comment bloquer à distance l'iPhone de mon enfant ?

Installez Blok sur votre iPhone et sur celui de votre enfant, puis associez-les avec un code. Appuyez ensuite sur LOCK dans l'app sur votre téléphone : les applications choisies sont bloquées sur le téléphone de votre enfant. Vous pouvez bloquer jusqu'à nouvel ordre, pendant une durée définie ou selon des horaires.

En combien de temps le blocage s'applique-t-il ?

Le blocage est envoyé immédiatement au téléphone de votre enfant, mais la rapidité dépend de sa connexion et d'iOS. Si le téléphone est hors ligne, le blocage s'applique dès son retour, et l'app réessaie jusqu'à ce que le téléphone ait répondu. Une application déjà ouverte est bloquée dès que votre enfant change d'app ou déverrouille l'écran. Votre téléphone indique quand celui de votre enfant a confirmé le blocage.

Quelle différence entre Blok et Temps d'écran d'Apple ?

Blok repose sur Temps d'écran, mais le transforme en un seul geste depuis votre propre téléphone : blocage immédiat, blocages minutés et horaires, avec un bouton clair qui montre si le téléphone de votre enfant est bloqué.

De quoi mon enfant a-t-il besoin ?

D'un iPhone sous iOS 16 ou version ultérieure avec Blok installé. Votre enfant n'a pas besoin de compte. Vous autorisez Temps d'écran une seule fois sur son téléphone lors de l'association.

Mon enfant peut-il lever le blocage ?

Les réglages sont protégés par votre code PIN et iOS applique le blocage, qui tient même si l'app est fermée ou si le téléphone redémarre. Le seul moyen de le contourner est une réinitialisation d'usine du téléphone, ce qu'aucun contrôle parental ne peut empêcher.

Mon enfant peut-il encore téléphoner ?

Oui. Vous choisissez quelles applications sont bloquées : Téléphone et Messages peuvent rester accessibles. Les appels d'urgence fonctionnent toujours.

Blok surveille-t-il ce que fait mon enfant ?

Non. Blok ne lit aucun message, ne suit pas la localisation et ne collecte pas les applications utilisées par votre enfant. Le choix des applications à bloquer reste sur le téléphone de votre enfant.

Puis-je bloquer TikTok, YouTube, Snapchat ou les jeux ?

Oui. Lors de l'association des téléphones, vous choisissez quelles applications de l'iPhone de votre enfant seront bloquées, par exemple TikTok, YouTube, Snapchat, Instagram, Roblox ou d'autres jeux. Téléphone, Messages et toutes les applications que vous voulez laisser ouvertes continuent de fonctionner.

Combien coûte Blok ?

Blok propose un abonnement, Blok Plus, dont le prix pour votre pays est affiché dans l'App Store. Le déblocage du téléphone de votre enfant fonctionne toujours, même sans abonnement. Blok ne contient aucune publicité.

Existe-t-il d'autres applications appelées Blok ?

Oui, le nom est courant. Cette application s'appelle Blok : Contrôle parental et elle est conçue pour les familles : un parent bloque les applications de l'iPhone de son enfant depuis son propre iPhone. Ce n'est pas une application pour limiter votre propre temps d'écran. Repérez l'icône : un cadenas blanc sur un cercle bleu.

Blok fonctionne-t-il sur Android ?

Pas encore. Blok est conçu pour l'iPhone, pour vous comme pour votre enfant.
