Comment bloquer TikTok, YouTube et les jeux sur l'iPhone de votre enfant

Mis à jour le 4 novembre 2026

Pour bloquer TikTok, YouTube, Snapchat ou Roblox sur l'iPhone de votre enfant, fixez une limite quotidienne très courte avec Temps d'écran, ou choisissez ces apps dans une application de contrôle parental comme Blok et bloquez-les depuis votre téléphone quand vous voulez. Dans les deux cas, bloquez aussi Safari et l'installation d'apps, sinon les sites web restent accessibles.

Avec Temps d'écran d'Apple

  1. Sur votre iPhone, ouvrez Réglages → Temps d'écran et touchez le nom de votre enfant sous Famille.
  2. Touchez Limites d'app → Ajouter une limite, choisissez les apps (par exemple TikTok et YouTube) ou toute une catégorie comme les jeux, puis réglez la durée quotidienne.
  3. Activez Bloquer en fin de limite : votre enfant devra vous demander l'autorisation pour avoir plus de temps.
  4. Utilisez Temps d'arrêt pour tout bloquer, sauf les apps autorisées, la nuit ou pendant les heures de classe.

Les Limites d'app comptent un temps par jour ; elles ne vous donnent pas d'interrupteur pour bloquer une app tout de suite et la rouvrir une heure plus tard.

Avec Blok : choisissez les apps, bloquez-les quand vous le décidez

  1. Installez Blok sur les deux iPhone et associez-les avec un code.
  2. Sur le téléphone de votre enfant, choisissez les applications à bloquer, par exemple TikTok, YouTube, Snapchat, Instagram, Roblox et d'autres jeux. Ce choix reste sur le téléphone de votre enfant.
  3. Touchez VERROUILLER sur votre propre téléphone : jusqu'au déblocage, pendant 30 minutes, 1 heure ou 2 heures, ou selon des horaires pour les devoirs et le coucher.

Tout le reste continue de fonctionner, y compris Téléphone et Messages. Vous pouvez bloquer jusqu'à trois téléphones d'enfants, chacun séparément.

Télécharger Blok dans l'App Store

Fermez les failles

  • Le navigateur. TikTok et YouTube fonctionnent aussi dans Safari. Bloquez Safari également, ou limitez les sites web dans Temps d'écran → Restrictions relatives au contenu et à la confidentialité.
  • Les nouvelles apps. Dans Restrictions relatives au contenu et à la confidentialité → Achats dans l'App Store, interdisez l'installation d'apps, pour qu'une app bloquée ne puisse pas être remplacée par une app similaire.
  • Le code. Utilisez un code de Temps d'écran ou le code PIN parent de Blok que votre enfant ne connaît pas.

Questions

Bloquer une app efface-t-il les données de mon enfant ?

Non. Un blocage Temps d'écran empêche seulement l'app de s'ouvrir. Les comptes, les messages et la progression dans les jeux sont toujours là quand l'app est débloquée.

Puis-je bloquer TikTok uniquement le soir, au coucher ?

Oui. Utilisez Temps d'arrêt dans Temps d'écran, ou un horaire dans Blok qui bloque les apps choisies chaque soir et les débloque le matin.

Mon enfant peut-il contourner le blocage ?

Pas en fermant l'app ni en redémarrant le téléphone, car c'est iOS qui applique le blocage. Gardez votre code ou votre code PIN secret et bloquez l'installation de nouvelles apps. Seule une réinitialisation complète supprime le blocage, et aucun contrôle parental ne peut l'empêcher.
